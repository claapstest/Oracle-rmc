## 2. Why This Candidate

Selected using the criteria in Section 10.1 of the implementation plan:

- **Clear boundary:** one function, one return value (`structuredData` view model).
- **Deterministic inputs/outputs:** `intent`, `parameters`, `toolResult`, `synthesisJson` in; plain object out.
- **No shared mutable state** and no external calls.
- **Lowest contract risk:** `processUserMessage` still assembles the `AIResponse`; only the formatter moved.
- **Not owned by another story:** intent/fallback/parameter extraction belongs to VEYRA-102; registry/dispatch to VEYRA-202.

`fallbackNLU` (L25–1703), `generateFallbackExplanation` (L1704–2298), and the `processUserMessage` pipeline (L2299–3133) remain in `orchestrator.ts` as allocated.
